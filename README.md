## Главное окно

Распознавание включается автоматически после открытия программы. Просто приложите палец: появится живое изображение, после качественного неподвижного кадра (около двух секунд) — псевдоним зелёным или «Не найден». Вводить псевдоним для распознавания не требуется. Поле «Псевдоним» используется только для сохранения новой серии и запоминается между запусками.

Один результат выдаётся на одно касание. Пока палец остаётся на стекле, повторного сравнения нет. Уберите его не менее чем примерно на полсекунды, затем приложите следующий. Последний результат остаётся видимым до нового касания.

На главном экране нет ползунка порога и кнопки «Распознать»:

- **Считать** — временно приостанавливает фоновое распознавание и начинает сохранение новой серии под введённым псевдонимом.
- **ОК** — ручное сохранение подходящего кадра, если авто-сохранение выключено.
- **Завершить** — завершает сохранение серии; затем фоновое распознавание возобновляется.
- В фоновом режиме эта кнопка называется **Пауза**; после остановки — **Продолжить**.
- **Шестерёнка Setup** — открывает настройки, на время диалога приостанавливая работу со сканером. После закрытия фоновый режим возобновляется, если до этого пользователь не нажал «Пауза».

При регистрации новой серии снимки принимаются по отдельным прикладываниям того же пальца с небольшим изменением положения. Дождитесь счётчика 5/5 (или количества из Setup). Уже принятые снимки остаются при отмене. После регистрации приложение ждёт снятия пальца перед очередным распознаванием. Номер пальца не используется.

Распознавание не сохраняет кадры, результаты попыток или новые шаблоны на диск. Все операции выполняются локально. Одновременно со сканером работает только один режим.

## Setup

В отдельной форме находятся папка базы/сохранения, авто-сохранение, серия и количество снимков 2–10, **порог распознавания 30–60** и сброс к 40. «Сохранить» применяет настройки; «Отмена» отбрасывает изменения. Псевдоним и прежний выбранный порог сохраняются при обновлении программы.

Порог ниже — меньше отказов знакомому пальцу, но выше риск ложного совпадения; выше — обратный эффект. Это экспериментальный диапазон приложения, не проценты FAR/FRR/EER и не сертифицированные безопасные пределы. После попытки показаны балл и использованный порог. Отрыв от второго псевдонима должен оставаться не меньше 8 независимо от порога; при неоднозначности выводится «Не найден». Порог фиксируется на время фонового сеанса; изменения через Setup безопасно перезапускают его с новым значением.

Настройки хранятся в `%LOCALAPPDATA%\FutronicFS80H\settings.json`: SaveDirectory, Alias, Auto, Series, Samples, RecognitionThreshold. Повреждённые настройки не мешают открытию программы. Старые файлы с отсутствующими параметрами читаются с исходными значениями (Авто, серия из пяти, порог 40). Если папка отсутствует — выберите её в Setup. Если база пуста, сначала сохраните серию; после этого фон запустится автоматически.

## Изображение и индикатор

Предпросмотр обновляется без дополнительной фиксированной паузы 100 мс, с переиспользованием Bitmap. Время SDK входит в ограничение полного цикла 33 мс (успешный кадр) / 20 мс (временное отсутствие кадра); это программные пределы, не обещание FPS сканера. Сохраняются исходные пиксели полного разрешения, уменьшено только изображение на форме.

Короткие состояния: «Ожидание», «Сканирование», «Сравнение», «Готово», «Остановлено», «Ошибка». Детали доступны при наведении на состояние.

Зелёная лампочка включается на старте, горит при захвате и мигает в ожидании. В непрерывном режиме после результата снова продолжается ожидание следующего касания, поэтому мигание продолжается. При паузе и обычном закрытии индикатор выключается. Все вызовы SDK выполняются последовательно. Аварийное завершение процесса, отключение USB или зависший SDK могут помешать отправке команды выключения. При зависшем нативном вызове отмена ждёт его возврата.

## База и распознавание

Каждый принятый снимок — уникальный `fingerprint_<UTC-время>_<GUID>.zip`, без перезаписи. Внутри `image.raw` (Gray8, width × height байт), `image.png` с той же пиксельной матрицей, `metadata.json` schemaVersion 3. Метаданные содержат alias, UTC-время, размеры/формат, ссылки на изображения, источник и сведения о серии: SessionId, номер снимка, запрошенное количество, подсказку положения, режим и время стабильности.

Имя файла не содержит псевдонима. Номер пальца в новых файлах отсутствует. Старые архивы v1/v2 не переписаны: имя/псевдоним читается из user, в v3 — из alias. Пустая/полностью непригодная база показывается ошибкой; отдельные плохие архивы пропускаются. База загружается при запуске фонового режима и после результата; регистрация и смена папки также перезагружают её. Шаблоны кешируются только в памяти, с проверкой содержимого архивов.

Используется SourceAFIS 3.14.0: извлечение minutiae и сравнение вариантов, 500 DPI. Буфер FS80H инвертируется только в памяти в требуемую полярность; исходные архивы не меняются. Для псевдонима берётся максимальный балл по его снимкам. Балл не является процентом вероятности. Порог 40 — исходная настройка, не измеренная точность этой базы.

Качество/стабильность перед принятием кадра: экспериментальная текстурная оценка contrast-texture-v1, средняя разница с предыдущим кадром ≤5 уровней Gray8 и с начальным кадром интервала ≤8, не менее двух секунд и шести кадров, без разрывов >1 секунды. При сохранении практически одинаковые варианты отсекаются по уменьшенной сетке. Снятие пальца определяется по пустому кадру SDK 4306 на протяжении ≥0,4 секунды; движение и временное отсутствие кадра не считаются снятием.

ZIP не зашифрован и содержит биометрические данные. Используйте локальную папку с ограниченным доступом. Буферы очищаются после использования; полное удаление всех копий из памяти ОС не гарантируется. Приложение не собирает имя Windows/серийный номер устройства. LFD не включён. Это учебный распознаватель, не готовая система контроля доступа.

## Исходники, зависимости и запуск

Program.cs — SDK и архивы; MainForm.cs — интерфейс и переключение режимов; SetupForm.cs — настройки; Imaging.cs — изображение/качество/стабильность; Recognition.cs — база, сравнение и контроль касаний; OutputPreferences.cs — настройки; ScannerIndicator.cs — лампа.

Для сборки установите .NET SDK 10 на Windows. DLL Futronic в Git не включены: скачайте официальное Windows demo ftrScanApiEx_v4.5.zip со [страницы загрузок Futronic](https://www.futronic-tech.com/download.php) и скопируйте его DLL x86 в папку native: ftrScanAPI.dll, ftrMathAPI.dll, ftrWSQ.dll и LiveFinger2.dll. Установите официальный драйвер сканера. Не смешивайте DLL x86 и x64. После этого выполните команды ниже. ZIP с отпечатками, личные настройки и готовые сборки также исключены из Git.

SourceAFIS собран из upstream v3.14.0 в thirdparty/SourceAFIS, алгоритм извлечения/сравнения не менялся. Удалён только ненужный декодер PNG/JPEG: движок принимает исходный Gray8 без ImageSharp. Лицензии и описание изменений — THIRD-PARTY.md, thirdparty/SourceAFIS/LICENSE, licenses/.

Каждая команда PowerShell ниже — одна строка, из рабочей папки Finger:

```powershell
dotnet publish .\FS80H.csproj -c Release -r win-x86 -p:PlatformTarget=x86 --self-contained true -o .\publish-x86
```

```powershell
& '.\publish-x86\FS80H.exe'
```

```powershell
dotnet publish .\work\tests\tests.csproj -c Release -r win-x86 -p:PlatformTarget=x86 --self-contained true -o .\work\tests-x86
```

```powershell
& '.\work\tests-x86\tests.exe'
```

Тесты используют искусственные изображения и публичные фикстуры SourceAFIS; тестовые архивы удаляются. Пользовательские отпечатки при автоматических тестах не считываются. work исключён из сборки приложения.
