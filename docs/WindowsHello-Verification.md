# Проверка FingReader.WindowsHello 1.0.0 — 23.10.2026

- Библиотека собрана для net8.0-windows10.0.22000.0, AnyCPU. Публичный API не содержит типов WinRT или WinForms.
- 36 автоматических проверок: только Verified разрешает доступ; значение по умолчанию и неизвестные ответы закрыты; неверный HWND и предварительная отмена не открывают окно; отмена перекрывает поздний успех; исключения не разрешают доступ; второй одновременный запрос получает DeviceBusy; после исключения очередь освобождается; неоднозначное окно не выбирается; переключение в чужое приложение учитывается при передаче фокуса.
- Отдельное приложение-потребитель локального NuGet-пакета собрано и запущено как x64 и x86. В обоих случаях CheckAvailabilityAsync вернул Available; неверный HWND и отмена обработаны. Эти проверки не запрашивали отпечаток/PIN.
- Полный WinForms-пример собран по прямой бинарной ссылке на DLL, без ProjectReference библиотеки. Самопроверка состояний приложения прошла.
- Пользователь подтвердил живую автоматическую разблокировку этого бинарного примера: системное окно Hello выходит вперёд, FS80H принимает палец, доступ открывается.
- Драйверы, PIN, UAC и политики входа во время выделения DLL не изменялись. База FingReader не использовалась, отпечатки/псевдонимы в комплект не включены.

Ограничения: не выполнялась живая проверка WPF/WinUI, переиспользования окна системного брокера и одновременных запросов разных приложений. Работа отмены нативного системного окна зависит от Windows (best effort); отказ в доступе после отмены проверен отдельно на уровне библиотеки. FAR/FRR и способ подтверждения не определяются этой DLL.
